# Library selection and presets

The web editor's left rail has a Libraries and presets gear. A fresh normal editor keeps the existing group rail; a new shared board starts with the gear alone. The dialog enumerates the pinned native sidebar catalog without loading catalog preview images. Apply selects the visible rail buttons. Opening a selected palette uses draw.io's existing deferred palette initialization. The bundled editor and shape definitions still have a baseline cost: this is not a reduction in engine download size. Closing/disabling a palette never unregisters stencils or removes document cells.

Named presets (up to 30, names unique ignoring case, 80 characters) are saved in this browser under the EMC user ID. They contain only library IDs, no diagrams, credentials or session contents. In the normal editor, Remember as my editor default persists the chosen rail; otherwise Apply affects this window only. Applying a preset on a shared board changes that session only. Saving a named preset makes it reusable in future sessions. Presets do not synchronize across devices.

Only the current fenced editor can apply a shared library selection. It travels as `libraryIds` in the same standard/encrypted snapshot and queued write as XML, with the same writer epoch. Observers receive it on polling/realtime updates and cannot change it. No new persistent database column is required. Session deletion removes the session selection together with its snapshot. Saved `.drawio` copies contain the drawing, not participants' personal presets.

EM metadata/definitions are fetched only when its palette is opened/a symbol inserted. The EMC parent brokers read-only requests through `brainstorm-shared-library`; no token crosses to the Worker iframe. The endpoint checks canonical origin, sign-in, accepted session membership/MFA/secure device authority through the existing session RPC, and reads only nondeleted symbol metadata or the database-owned definition path. It rechecks session access after a definition download. It provides no create/delete action. A control change prevents pending symbol insertion.

Verification: frontend unit/type/lint checks and shared-canvas Playwright fixture (gear-only start, observer denial, editor selection, palette opening, existing drawing preservation); backend shared-window checks in both security modes and Edge runtime authorization tests.
